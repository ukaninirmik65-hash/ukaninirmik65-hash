# Profile visuals

All README images are committed locally. A third-party image server outage therefore cannot break an already published header, skill icon, or chart.

- `hero.svg`, `hero-mobile.svg`, `footer.svg`: generated with [Capsule Render](https://github.com/kyechan99/capsule-render), using a muted navy/cyan/purple gradient and its `twinkling` animation. Header says “NIRMIK UKANI” and “Frontend Developer | React.js Developer.” Footer says “Building interfaces. Solving problems. Growing every day.” The mobile header has a larger subtitle for readability.
- `typing.svg`, `typing-mobile.svg`: generated with [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg), using the six role phrases in the profile brief. The mobile version increases text size.
- `skills-*.svg`: cached [Skill Icons](https://github.com/tandpfun/skill-icons) for the confirmed technologies; TypeScript and Next.js are explicitly labeled as learning in the README.
- `portfolio-button.svg`: original static button asset.
- `latest-repositories*.svg`, `github-statistics*.svg`, `contribution-graph*.svg`, `github-languages*.svg`, `profile-data.json`: generated by `scripts/update-profile.mjs` using actual GitHub data. Do not edit these files manually. Each chart has a narrow-screen version selected with GitHub-compatible `<picture>` markup.

The downloaded brand graphics contain SVG/CSS animation only; they do not execute JavaScript. Keep the static name, role and meaningful alt text if changing the animation. Metric cards are deliberately unanimated for readability.
